## 結果
ゲームの仕組み
1. HPの振り分け
2. こうげき、にげるの選択
3. ランダムなダメージでこうげき
4. 逃げる確率の作成
5. HPが０になるかにげきるまでこうげき、にげる選択の繰り返し
6. HPが０未満にならない

## 考察
今回作ったポケモンバトルはこうげきと逃げるの選択だけでしかバトル方法がなく、攻撃もワンパターンだったのでこのゲームをプレイする人がいるとすぐに飽きてしまうと考えられる。

## 考察　vol2
自分が作ったプログラムとAIに作成させたプログラムを見比べたフィードバック
### 自分が使っていなかったコマンド
- def（関数を定義するための命令）
- return（関数の処理結果を、呼び出しもとに持ち帰るための命令）
- if __name__ == "__main__":
    main()
    （このファイルが直接実行されたときだけ、中の処理を動かすための条件分）
###　改善
- HP_MAXやMIN_DAMAGE、MAX_DAMAGE、ESCAPE_RATEなどの数値を最初に指定しているので後でダメージ量やHPの数値を変更したいときに一箇所だけを変更するだけで良くなるようになっている
- 同じ処理をコピペしなくて済むようにattack(enemy, player)と打つだけで攻撃の過程などのコードが通るようになっている
- たくさんある処理を関数で分けてバトルの流れがわかりやすくしている
- ポケモンの名前とHPをmake_pokemon()という辞書にまとめることでポケモン自体をつくることができ、プレイヤーが選択できる仕組みができるので、ポケモンが増えても追加しやすくしている。（自分はplayer,player_HPなど、ポケモンが元々決められていた）

## ネクストアクション
今回はポケモンバトルの基盤を作成することができたので、バトルの行動を増やすことが大事だと考えられるため、追加する機能の案として、
- 攻撃の種類を増やす
- ポケモンの種類を増やす
- ポケモンと攻撃にタイプを持たせて相性によってダメージの倍率を変更する
- 攻撃するときに低確率で急所に当たるようにする
- アイテムで回復することができるようにする
などの機能を追加することで、ポケモンバトルの幅が広がると考えられる。
